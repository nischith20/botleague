# BotLeague – India's Robotics Competition Platform

A frontend-only React + Vite application for BotLeague, a national robotics competition platform. 

## Tech Stack

- React
- Vite
- Tailwind CSS

## Features

- Landing page with hero section
- Competitions & Events section (Live, Upcoming, Past Results)
- User journey / how it works section
- Categories and competition disciplines
- Registration forms (Judge, Volunteer, Community Member)
- Sponsors section
- Footer with quick links and social media

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
git clone https://github.com/nischith20/botleague.git
cd botleague
npm install
```

### Running locally

```bash
npm run dev
```

The app will be available at `http://localhost:5173` (or whichever port Vite assigns).

### Building for production

```bash
npm run build
```
